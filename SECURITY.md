# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk. Contact the maintainer privately with:

- the affected version or commit;
- reproduction steps;
- expected and observed behavior;
- potential impact;
- a suggested mitigation, if available.

Do not include real secrets, personal data, or test results from systems you do not own.

## Scope and responsible use

Siper performs passive HTTP and TLS configuration checks. It must not be used to probe systems without authorization. Reports are informational and do not replace a professional penetration test.
