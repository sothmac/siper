# Contributing

Contributions that improve safe, passive web-security checks are welcome.

1. Open an issue describing the change.
2. Keep checks passive and deterministic.
3. Add or update tests.
4. Run `npm test` before opening a pull request.
5. Avoid adding telemetry, secret collection, exploit code, brute force, or authenticated scanning.

By contributing, you agree that your contribution is licensed under the MIT License.
